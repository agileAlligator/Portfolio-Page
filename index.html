Things I've built

A secure-by-default MCP framework

Client work at Gruve · Python · OAuth 2.1

A client wanted internal AI agents talking to enterprise systems without betting company data on the model behaving. I built a framework and a tested Python scaffold that make the secure path the default: endpoint allowlists, token checks on every call, scanned tool output, and an audit trail. Every server it produces passes a readiness checklist before it ships.

The client and the internals stay anonymous. The checklist is still the part I'm proudest of.

Helix

Internal platform at Gruve · Express, PostgreSQL, Redis, Azure

Gruve's sales-enablement platform. It drafts statements of work with GPT-4o, prices engagements, and maps engineering capabilities, so the sales team stops rebuilding the same documents by hand.

helix.gruveai.com (sign-in required)

Colleagues are a harder audience than clients. They tell you when it's broken.

mcploitable

Open source · Security training lab · Python

Deliberately vulnerable MCP servers, one for each risk in the OWASP Top 10 for agentic apps. You attack them in the browser and score only when a planted secret actually leaves. Guardrails that rely on the model noticing an attack fall. The one in server code held for 105 attempts out of 105.
